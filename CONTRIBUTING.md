# Contributing to Meforash

Meforash is an experimental English Bible assistant built around original-language model fine-tuning. Contributions to source provenance, evaluation, accessibility and the application are welcome. Start with the [project charter](docs/PROJECT_CHARTER.md), [execution plan](docs/EXECUTION-PLAN.md) and [evaluation runbook](docs/EVALUATION-RUNBOOK.md).

For a source or answer correction, identify the passage, edition or witness and the specific claim. Cite evidence and distinguish an error from a defensible translation or interpretation. Automated review is useful but is not expert certification.

Use constructed examples when filing issues. Do not post private conversations, credentials, provider checkpoint addresses, account records or copyrighted material without appropriate permission. Never assume that a user submitting feedback has consented to training on their conversation.

Keep changes focused. Run the relevant offline tests and explain what was verified. Model calls, training, deployment and checkpoint changes require a separately bounded project decision. Do not change the selected model or frozen experiments as part of an unrelated feature.

Original code and documentation use Apache-2.0. Third-party material keeps its own rights and attribution requirements; include provenance and a use-specific license assessment with new sources. See [publication practices](docs/PUBLICATION.md).
