# Reporting a security issue

Please report suspected vulnerabilities privately to **support@meforash.com**.
Use a subject such as "Meforash security report" and describe the affected
feature, potential impact and steps to reproduce using a test account or
constructed example.

Do not put credentials, sign-in codes, private conversations, account records
or sensitive exploit details in public GitHub issues. Do not access other
people's data, disrupt the service, or generate high volumes of paid model
requests to demonstrate a problem. If a report needs sensitive evidence,
describe what you have first so an appropriate transfer can be arranged.

The project is an actively developed beta. Reports are welcome, but there is
no guaranteed response time or bug-bounty payment. Older commits and
self-hosted forks do not have a separate maintenance commitment.

For ordinary bugs and source corrections, see [CONTRIBUTING.md](CONTRIBUTING.md).
For how the hosted service handles information, see the
[Privacy Policy](https://meforash.com/privacy).
